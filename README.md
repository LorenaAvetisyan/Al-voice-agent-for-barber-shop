# 🤖 AI Barber Assistant

**AI Barber Assistant** is an intelligent, voice-powered agent built for barbershops.  
It automates appointment scheduling, client reminders, and customer communication through seamless AI and automation integrations.

---

## ✂️ Overview

AI Barber Assistant helps barbershops save time and deliver a better client experience by managing appointments, sending notifications, and handling conversations — all powered by artificial intelligence.

---

## ⚙️ Features

- 📅 **Automated Scheduling:**  
  Connects to your **Google Calendar** to create, modify, and confirm bookings automatically.

## 💡 Example Workflow

1. A client calls the barbershop.  
2. The AI assistant answers with a friendly voice (via ElevenLabs).  
3. The client requests a haircut appointment.  
4. The agent checks availability in Google Calendar.  
5. The appointment is confirmed.  
6. A confirmation SMS is sent automatically via Twilio.  
7. All data and workflows are handled by Make automation.
